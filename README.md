# Excel2GuanLiDe

**Excel → 管立得 / AutoCAD 管网数据自动化工具** 🚰📐

目标：把设计人员每天需要手工录入、整理、定位的 Excel 管网数据，尽量变成“一键识别 → 自动生成节点 → 自动拓扑 → 纵断面”。

## 当前版本：V0.3

已加入 AutoCAD 2018 .NET 插件能力：

- Excel `.xlsx/.xlsm`、CSV 导入
- 自动识别桩号、节点编号、地面高程、管底高程、管径、管材、节点水压
- 自动识别 **起点/终点**：起点、起点节点、起始节点、from、start；终点、终点节点、终止节点、to、end
- 桩号支持 `K0+000`、`K1+235.6`、纯数字米数
- 相同桩号自动合并，缺失节点自动生成 `N001、N002...`
- **EXCEL2GLD**：Excel 一键生成节点、桩号、高程、节点编号，并自动生成管线
- **GLDPIPE**：生成管线中心线
- **GLDTOPO**：有起点/终点时按真实拓扑生成，支持分支和环路；无起终点时按桩号顺序生成
- 自动标注管径、管材
- **GLDPROFILE**：生成纵断面地面线、管底线、桩号、高程及节点水压 `P=`
- **GLDSETTINGS**：统一设置水平比例、纵向比例、文字高度和文字偏移
- GitHub Actions 自动编译 AutoCAD 2018 插件

| 序号 | 桩号 | 节点编号 | 地面高程 | 管底高程 | 管径 | 管材 | 节点水压 | 起点 | 终点 | 备注 |
|---:|---|---|---:|---:|---:|---|---:|---|---|---|
| 1 | K0+000 | W1 | 1523.600 | 1522.100 | 400 | HDPE | 28.60 | W1 | W2 | |
| 2 | K0+120 | W2 | 1522.800 | 1521.300 | 400 | HDPE | 27.80 | W2 | W3 | |
| 3 | K0+260 | W3 | 1521.900 | 1520.400 | 400 | HDPE | 26.90 | W3 | W4 | |

起点/终点可以填写节点编号，也可以填写 `K0+120`、`120` 等桩号。

## AutoCAD 2018 使用

1. 在 AutoCAD 2018 输入 `NETLOAD`。
2. 加载 GitHub Actions 编译得到的 `Excel2GuanLiDe.dll`。
3. 输入 `GLDSETTINGS`，可先设置比例。
4. 输入 `EXCEL2GLD`：选择 Excel 后自动生成节点和管线。
5. 输入 `GLDTOPO`：推荐用于有分支、环网、明确起终点关系的项目。
6. 输入 `GLDPROFILE`：生成纵断面。
7. 输入 `GLDPIPE`：只生成管线中心线。

如果 AutoCAD 因安全策略拒绝加载 DLL，可将插件所在文件夹加入 `TRUSTEDPATHS`。

## 图层

- `Excel2GLD_NODE`：节点
- `Excel2GLD_TEXT`：桩号、高程、节点编号
- `Excel2GLD_PIPE`：管线中心线
- `Excel2GLD_PIPE_TEXT`：管径、管材
- `Excel2GLD_PROFILE_GROUND`：纵断面地面线
- `Excel2GLD_PROFILE_INVERT`：纵断面管底线
- `Excel2GLD_PROFILE_TEXT`：纵断面文字

## 当前实现边界

当前插件生成的是 AutoCAD 实体，可作为管立得 2024 的辅助绘图/数据准备工具；**尚未声称能够直接写入管立得私有数据库格式**。真正的“Excel 一键导入管立得”适配，需要依据管立得 2024 的实际导出/导入样例或官方接口继续开发。
