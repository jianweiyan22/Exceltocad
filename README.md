# Excel2GuanLiDe

Excel → 管立得 自动化工具（开发中）

## 项目目标

将 Excel 中的给排水管网数据自动转换为可供 AutoCAD / 管立得使用的数据，减少人工录入。

### 第一阶段功能
- 读取 Excel 表格
- 自动识别桩号、管径、管底/地面高程等字段
- 桩号标准化与排序
- 根据桩号生成节点
- 节点与管线关系匹配
- 输出 CAD / 管立得可进一步处理的数据

### 计划支持
- 管立得 2024
- AutoCAD 2018+
- Windows 10 / Windows 11

## 当前状态

项目已建立基础仓库，第一版核心功能开发中。
