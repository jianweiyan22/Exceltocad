# Excel2GuanLiDe 开发路线

## V0.1 数据识别
1. Excel 文件读取
2. 自动识别表头
3. 识别桩号格式，例如 K0+000、0+120、K1+235.6
4. 高程、管径、管材、节点编号等字段识别
5. 数据检查与异常提示

## V0.2 节点生成
1. 根据桩号自动生成节点
2. 相同桩号自动合并
3. 节点编号自动生成
4. 节点高程自动匹配
5. 节点与上下游管线建立关系

## V0.3 CAD / 管立得对接
1. 输出 AutoCAD 可识别的数据
2. AutoLISP 自动绘制节点
3. 自动绘制管线
4. 自动标注桩号和高程
5. 为管立得纵断面数据提供自动化输入

## V1.0
目标：形成 Windows 下可直接运行的 Excel → 管立得辅助工具，尽量做到选择 Excel 后一键处理。
